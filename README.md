# 🛍️ LocaSell

**LocaSell** is a local second-hand marketplace where users can buy and sell unused products within a **20 KM radius**.

Discover nearby products, connect with sellers, and give unused items a new value through a simple and secure platform.

---

## 🌐 Live Demo

🔗 Website: https://loca-sell.vercel.app

---

## ✨ Features

- 🔐 JWT Authentication
- 👤 User Registration & Login
- 📦 Create and manage product listings
- 🔍 Search and advanced filters
- 📍 Location-based product discovery within 20 KM
- ❤️ Wishlist management
- 💬 Real-time buyer and seller chat
- 🔔 Notifications
- 🗺️ Interactive maps with React Leaflet
- 👤 User profiles and listing history
- 🌙 Dark / Light theme

## ⚙️ Installation

### Clone Repository

```bash
git clone <repository-url>
cd LocaSell
```

---

## Backend Setup

```bash
cd backend
npm install
```

Create a `.env` file inside the backend folder:

```env
PORT=
MONGO_URI=
JWT_SECRET_KEY=
CLOUDINARY_NAME=
CLOUDINARY_KEY=
CLOUDINARY_SECRET=
```

Run backend:

```bash
npm run server
```

---

## Frontend Setup

```bash
cd frontend
npm install
```

Create a `.env` file:

```env
VITE_API_URL=
```

Run frontend:

```bash
npm run dev
```

## 📱 Usage

1. Create an account or login.
2. Set your location.
3. Browse nearby products.
4. Search and filter items.
5. Contact sellers through chat.
6. Add products to wishlist.
7. Create your own listings and sell locally.
